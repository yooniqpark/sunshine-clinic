# ✍️ 글쓰기 듀오 — Claude × GPT가 대화하며 함께 쓰는 글

채팅창에 주제만 적으면 **Claude(작가)** 가 쓰고 **GPT(편집자)** 가 점수와 고칠 점을 짚어주며,
목표 점수가 될 때까지 둘이 알아서 주고받습니다. 그 대화가 채팅처럼 실시간으로 보이고, 기록은 자동 저장됩니다.

- 💬 **채팅 화면**: 두 AI가 주고받는 원고·피드백을 말풍선으로 보여줌
- 🗂 **대화 기록**: 왼쪽 목록에 자동 저장 (내 PC의 `data/duo.db` 파일에만 저장)
- 📎 **글 첨부**: 참고할 예시 글(말투 따라 쓰기) 또는 내 원고(채점·다듬기)를 붙여넣거나 .txt/.docx 파일로 불러오기
- 🔁 **이어서 수정**: 완성 후 "더 짧게" 같은 요청을 보내면 그 글을 계속 다듬기
- 📄 **워드 파일**: 최종 원고를 .docx로 받기 (구글 문서·한글에서도 열림)

---

## 🚀 시작하기

### ① 파일 내려받기
1. GitHub 저장소 페이지에서 브랜치를 `claude/dual-agent-writing-automation-9c6fp5` 로 바꿉니다
2. 초록색 **Code** 버튼 → **Download ZIP**
3. 압축을 풀고 `tools` → `writing-duo` 폴더로 들어갑니다

### ② 설치 (처음 한 번만)
| 윈도우 | 맥 |
|---|---|
| **`설치하기.bat`** 더블클릭 | **`설치하기.command`** 마우스 오른쪽 클릭 → **열기** |
| 파란 "PC 보호" 창이 뜨면 **추가 정보 → 실행** | "확인되지 않은 개발자" 경고가 뜨면 **열기** |
| "다시 실행하라"고 나오면 한 번 더 더블클릭 | 맥 로그인 비밀번호 입력 (글자가 안 보이는 게 정상) |

설치가 끝나면 메모장이 열립니다. API 키를 붙여넣고 저장하세요. (아래 "API 키 받기" 참고)

### ③ 실행
**`글쓰기.bat`** (맥은 **`글쓰기.command`**) 더블클릭 → 브라우저에 글쓰기 화면이 열립니다.

> ⚠️ 함께 뜨는 **검은 창을 닫으면 페이지도 멈춥니다.** 다 쓰고 나서 닫으세요.
> 브라우저가 안 열리면 주소창에 `http://127.0.0.1:8765` 를 입력하세요.

## 사용법

1. 아래 입력창에 주제와 조건을 자유롭게 적습니다 (예시 카드를 눌러도 됨)
   ```
   아침에 일어나자마자 피곤한 이유 3가지
   대상: 30~40대 직장인 / 분량: 8분 / 말투: 친근한 존댓말
   ```
2. **🎬 유튜브 / 📝 블로그** 중 하나를 고릅니다 (채점 기준이 달라집니다)
3. 필요하면 **📎 글 첨부**
   - **참고 예시 글**: 반응 좋았던 내 글, 닮고 싶은 글 → 말투·구성을 따라 씁니다 (베끼지는 않음)
   - **내 원고**: 직접 쓴 글 → 편집자가 채점하고 작가가 내 말투를 살려 다듬습니다
4. **Enter** 로 보내면 두 AI의 대화가 시작됩니다 (보통 5~10분)
5. 끝나면 **📄 최종 원고 워드 받기** 또는 **📋 복사**
6. 마음에 안 들면 같은 대화에서 "도입부를 더 강하게" 처럼 이어서 요청하세요

**⚙️ 설정** (왼쪽 아래): 연습 모드, 작가 역할 바꾸기(GPT가 쓰고 Claude가 편집), 목표 점수, 최대 수정 횟수

> 💡 **연습 모드**를 켜면 AI를 부르지 않아 비용 0원으로 화면 흐름만 볼 수 있습니다.
> API 키가 없으면 자동으로 연습 모드가 켜집니다.

## API 키 받기
ChatGPT Plus·Claude Pro/Max 같은 **월 구독과는 별개**로, 미리 충전해서 쓰는 API 크레딧이 필요합니다.

1. Claude: [console.anthropic.com](https://console.anthropic.com) → Settings → Billing 에서 충전 → **API Keys** 에서 키 만들기
2. GPT: [platform.openai.com](https://platform.openai.com) → Settings → Billing 에서 충전 → **API keys** 에서 키 만들기
3. `writing-duo` 폴더의 `.env` 파일을 메모장으로 열어 `여기에_클로드_키`, `여기에_오픈AI_키` 자리에 붙여넣고 저장
   (폴더에서 `.env` 가 안 보이면 "숨김 파일 보기"를 켜세요)
4. 페이지를 새로고침하면 왼쪽 아래 ⚙️ 설정 옆 점 두 개가 초록색이 됩니다

> 💡 결제 페이지에서 **자동 충전(Auto reload)을 꺼두면** 충전한 금액 이상은 나가지 않습니다.
> ⚠️ API 키는 비밀번호와 같습니다. 다른 사람에게 보내거나 인터넷에 올리지 마세요.

## `.env` 로 바꿀 수 있는 것

| 항목 | 기본값 | 설명 |
|---|---|---|
| `CLAUDE_MODEL` | `claude-opus-5-5` | 비용을 줄이려면 `claude-sonnet-5-5` |
| `GPT_MODEL` | `gpt-5` | 예: `gpt-5.4`, `gpt-5.5` (계정에서 쓸 수 있는 이름) |
| `WRITER` | `claude` | 기본 작가 역할 (화면의 설정에서도 바꿀 수 있음) |
| `TARGET_SCORE` | `8.5` | 기본 목표 점수 |
| `MAX_REVISIONS` | `3` | 기본 최대 수정 횟수 |

채점 기준이나 AI에게 주는 지시문은 `duo.py` 위쪽의 `RUBRICS`, `WRITER_SYSTEM`, `EDITOR_SYSTEM` 한글 문장을 고치면 됩니다.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 채팅에 "API 키가 올바르지 않습니다" | `.env` 의 키를 다시 복사해 넣고 페이지 새로고침 |
| "크레딧이 부족합니다" | 결제 페이지에서 충전 확인 (반영까지 몇 분 걸릴 수 있음) |
| "모델 이름을 쓸 수 없습니다" | `.env` 의 모델 이름 확인 |
| "프로그램과 연결이 끊겼어요" | 검은 창이 닫힌 것. `글쓰기` 를 다시 실행 |
| 대화 기록을 모두 지우고 싶음 | 프로그램을 끄고 `data` 폴더를 삭제 |

## 파일 구성 (참고용)
| 파일 | 역할 |
|---|---|
| `app.py` | 웹페이지 서버 (내 PC 안에서만 동작) |

| `db.py` | 대화 기록 저장 (SQLite — 파이썬에 기본 포함, 따로 설치 불필요) |
| `export_docx.py` | 워드 파일 만들기·읽기 |
| `web/index.html` | 채팅 화면 |
