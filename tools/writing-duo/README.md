# ✍️ 글쓰기 듀오 — 작가 AI × 편집자 AI 자동 협업

주제만 적어 넣으면 **작가 AI(Claude)** 가 초안을 쓰고, **편집자 AI(GPT)** 가 점수와 수정 지시를 주고,
작가가 다시 고치는 과정을 **자동으로 반복**해서 완성된 글을 만들어 줍니다.

```
의뢰서 작성 → 작가 초안 → 편집자 채점 → (점수 부족하면) 작가 수정 → 편집자 재채점 → … → 최종 원고
```

- 목표 점수(기본 8.5점) 달성, 편집자의 "큰 수정 없음" 판단, 최대 수정 횟수(기본 3회) 도달 중 하나라도 해당되면 멈춥니다.
- 결과는 `output/` 폴더에 **최종원고.md** 와 **작업기록.md**(회차별 점수·피드백·수정 내역)로 저장됩니다.

## 🚀 가장 쉬운 방법 (더블클릭만 하기)

### ① 파일 내려받기
1. GitHub 저장소 페이지에서 브랜치를 `claude/dual-agent-writing-automation-9c6fp5` 로 바꿉니다
2. 초록색 **Code** 버튼 → **Download ZIP** 을 누릅니다
3. 받은 ZIP 파일의 압축을 풀고 `tools` → `writing-duo` 폴더로 들어갑니다

### ② 설치 (처음 한 번만)
| 윈도우 | 맥 |
|---|---|
| **`설치하기.bat`** 더블클릭 | **`설치하기.command`** 를 **마우스 오른쪽 클릭 → 열기** |
| "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** | "확인되지 않은 개발자" 경고가 뜨면 **열기** |
| 파이썬 설치가 끝나고 "다시 실행하라"고 나오면 한 번 더 더블클릭 | 맥 로그인 비밀번호를 물으면 입력 (글자가 안 보이는 게 정상) |

설치가 끝나면 메모장(맥은 텍스트 편집기)이 열립니다. 여기에 API 키를 붙여넣고 저장하세요. API 키 받는 법은 아래 "API 키 받기"를 보세요.
키가 아직 없으면 그냥 닫아도 됩니다. 연습 모드는 키 없이 돌아가요.

### ③ 글쓰기
| 윈도우 | 맥 |
|---|---|
| 의뢰서 `.txt` 파일을 **`글쓰기.bat` 아이콘 위로 끌어다 놓기** | **`글쓰기.command`** 더블클릭 → 의뢰서 파일 이름 입력 |
| 그냥 더블클릭하면 연습 모드로 실행 | 그냥 엔터를 누르면 연습 모드로 실행 |

끝나면 결과 폴더가 자동으로 열립니다.

## API 키 받기
ChatGPT Plus·Claude Pro 같은 **월 구독과는 별개**로, 쓴 만큼 결제하는 API 키가 필요합니다.

1. Claude 키: [console.anthropic.com](https://console.anthropic.com) → 결제수단 등록 → **API Keys** → 키 만들기
2. GPT 키: [platform.openai.com](https://platform.openai.com) → 결제수단 등록 → **API keys** → 키 만들기
3. `writing-duo` 폴더의 `.env` 파일을 메모장으로 열어 `여기에_클로드_키`, `여기에_오픈AI_키` 자리에 붙여넣고 저장합니다.
   (`.env` 는 설치하기를 실행하면 자동으로 만들어집니다. 폴더에서 안 보이면 "숨김 파일 보기"를 켜세요.)

> ⚠️ API 키는 비밀번호와 같습니다. 다른 사람에게 보내거나 인터넷에 올리지 마세요.

## 매번: 글 쓰기

### 1. 의뢰서 작성
`briefs/` 폴더의 예시 파일(`youtube_example.txt`, `blog_example.txt`)을 복사해서 내용을 바꿔 적습니다.
첫 줄의 **`글 종류:`** 에 `유튜브 대본` 또는 `블로그` 라고 쓰면 그에 맞는 채점 기준이 자동 적용됩니다.

### 2. 실행
```
python duo.py briefs/내_의뢰서.txt
```
화면에 진행 상황과 회차별 점수가 표시되고, 끝나면 결과 폴더 위치를 알려줍니다.

### 💡 키 없이 먼저 연습해 보기
```
python duo.py briefs/youtube_example.txt --demo
```
AI를 실제로 부르지 않고 가짜 응답으로 전체 흐름만 보여줍니다. (비용 0원)

## 결과물 보는 법
`output/날짜_시간_파일이름/` 폴더 안에:

| 파일 | 내용 |
|---|---|
| `최종원고.md` | 완성된 글. 메모장으로 열어 복사해서 쓰면 됩니다 |
| `작업기록.md` | 점수 변화(예: 6.8 → 7.9 → 8.7), 회차별 피드백, 작가가 반영/거절한 내용 |
| `history.json` | 모든 버전의 원본 데이터 (보관용) |

작업기록 맨 위에 **"⚠️ 올리기 전에 직접 확인할 것"** 이 있으면, AI가 확신하지 못한 사실이니 꼭 직접 확인하세요.
원고 안의 `[확인 필요]` 표시도 마찬가지입니다.

## 설정 바꾸기 (`.env` 파일에서)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `WRITER` | `claude` | `gpt` 로 바꾸면 GPT가 작가, Claude가 편집자가 됩니다 |
| `TARGET_SCORE` | `8.5` | 이 점수 이상이면 멈춤. 높일수록 더 많이 고침(비용 증가) |
| `MAX_REVISIONS` | `3` | 최대 수정 횟수 |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 비용을 줄이려면 `claude-sonnet-5-5` |
| `GPT_MODEL` | `gpt-5` | OpenAI 계정에서 쓸 수 있는 다른 모델 이름으로 바꿔도 됩니다 |

채점 기준표나 AI에게 주는 지시문을 바꾸고 싶으면 `duo.py` 위쪽의 `RUBRICS`, `WRITER_SYSTEM`, `EDITOR_SYSTEM` 부분의 한글 문장을 고치면 됩니다.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| `.env 파일에 ... 가 없습니다` | "API 키 받기"를 다시 확인. 파일 이름이 `.env.txt` 로 저장되지 않았는지 확인 |
| 설치하기를 실행했는데 "파이썬이 없습니다"가 계속 나옴 | PC를 재시작한 뒤 다시 실행 |
| `401` / `authentication` 오류 | API 키가 틀렸거나 복사가 덜 됨 |
| `insufficient_quota` / `credit` 오류 | API 계정에 잔액(크레딧)이 없음. 결제 페이지에서 충전 |
| `model not found` 오류 | `.env` 의 모델 이름이 내 계정에서 쓸 수 없는 것. 콘솔에서 사용 가능한 모델 이름 확인 |
