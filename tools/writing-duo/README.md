# ✍️ 글쓰기 듀오 — Claude × ChatGPT가 토론하며 쓰는 병원 홍보 글

채팅창에 주제만 적으면 **Claude와 ChatGPT가 각자 글을 쓰고, 서로의 원고를 비판·반박하며 고친 뒤 하나로 합쳐** 완성합니다.
블로그 글과 유튜브 대본 모두 됩니다.

**API 키나 크레딧 충전이 필요 없습니다.** 이미 구독 중인 **Claude(Pro/Max)** 와 **ChatGPT(Plus/Pro)** 계정으로 로그인해서,
구독에 포함된 사용량 안에서 돌아갑니다. 모든 작업은 내 PC에서만 이뤄집니다.

- 🗣 **토론 모드 (기본)**: 각자 초안 → 서로 채점·비판 → 지적마다 "✅ 수용 / 🙅 반박" 하며 수정 → 점수가 높은 쪽이 두 원고를 합쳐 최종본 → 상대가 최종 검토
- ✍️ **작가·편집자 모드**: 한쪽이 쓰고 다른 쪽이 채점, 목표 점수까지 반복
- ⚖️ **의료광고 기준**: 의료법 제56조 요지(효과 보장·최상급·후기 남용 금지, 부작용·개인차 안내)를 지키며 쓰고, 채점 항목에도 들어갑니다
- 🔍 **주제 중복 확인**: 토론을 시작하기 전에 예전에 쓴 글과 겹치는지 먼저 확인하고, 겹치면 새 각도를 제안
- 🗂 **대화 기록** 자동 저장 · 📎 **참고 글/내 원고 첨부** · 🔁 **이어서 수정** · 📄 **워드(.docx) 받기**

## 🚀 시작하기 (윈도우)

### ① 파일 내려받기
1. GitHub 저장소 페이지에서 초록색 **Code** 버튼 → **Download ZIP**
2. 압축을 풀고 `tools` → `writing-duo` 폴더로 들어갑니다

### ② 설치 (처음 한 번만)
1. **`설치하기.bat`** 더블클릭
   - 파란 "PC 보호" 창이 뜨면 **추가 정보 → 실행**
2. 파이썬·Node.js·Git 이 없으면 자동으로 설치한 뒤 **"한 번 더 더블클릭"** 하라고 나옵니다. 창을 닫고 다시 실행하세요.
   (설치 중 "이 앱이 디바이스를 변경하도록 허용" 창이 뜨면 **예**)
3. 이어서 Claude Code·Codex(두 AI의 공식 프로그램)가 설치되고, **로그인 단계**로 넘어갑니다
   - **Claude**: 브라우저가 열리면 Claude **Pro/Max 구독 계정**으로 로그인 → 승인
   - **ChatGPT**: 브라우저가 열리면 **Sign in with ChatGPT** → Plus/Pro **구독 계정**으로 로그인
4. 마지막에 두 개 모두 "로그인됨"으로 나오면 끝

> 로그인만 다시 하고 싶으면 **`로그인하기.bat`** 을 실행하세요.
> ⚠️ 로그인 화면에서 "API 키로 로그인", "Console 계정" 을 고르면 구독이 아니라 크레딧이 쓰입니다. 꼭 **구독 계정**으로 로그인하세요.

### ③ 실행
**`글쓰기.bat`** 더블클릭 → 브라우저에 글쓰기 화면이 열립니다.

> ⚠️ 함께 뜨는 **검은 창을 닫으면 페이지도 멈춥니다.** 다 쓰고 나서 닫으세요.
> 브라우저가 안 열리면 주소창에 `http://127.0.0.1:8765` 를 입력하세요.

왼쪽 아래 **⚙️ 설정** 옆 점 두 개가 모두 **초록색**이면 준비 완료입니다. 빨간색이면 아직 로그인이 안 된 것이라 연습 모드로만 동작합니다.

## 사용법

1. 입력창에 주제와 조건을 자유롭게 적습니다 (예시 카드를 눌러도 됨)
   ```
   모공 치료에 대해서 블로그 글을 써줘
   쥬베룩을 미라젯포르테로 시술하고, 시크릿·포텐자 같은 니들 RF를 병합해서 치료해
   대상: 넓은 모공이 고민인 20~40대 / 2,000자 / 신뢰감 있는 말투
   ```
   💡 우리 병원이 실제로 쓰는 장비·시술 방식·주의사항을 적어줄수록 정확해집니다. 적지 않은 정보는 지어내지 않고 `[확인 필요]` 로 표시합니다.
2. **🎬 유튜브 / 📝 블로그** 중 하나를 고르고 **Enter**
3. 두 AI의 토론이 채팅처럼 보입니다 (보통 10~20분)
4. 끝나면 **📄 최종 원고 워드 받기** 또는 **📋 복사**
5. 마음에 안 들면 같은 대화에서 "도입부를 더 강하게" 처럼 이어서 요청하세요

**⚙️ 설정**: 진행 방식(토론 / 작가·편집자), 토론 라운드(기본 2), 목표 점수, 주제 중복 확인, 이미 올린 글 목록, 연습 모드

### 🔍 주제 중복 확인
새 글을 보내면 토론을 시작하기 전에 **예전에 쓴 글과 주제가 겹치는지** 먼저 확인합니다 (보통 10~30초).
- 비교 대상: 이 프로그램에서 쓴 글(제목·소제목·요청) + ⚙️ 설정의 **이미 올린 글 제목** 목록
  - 이 프로그램을 쓰기 전에 블로그·유튜브에 올린 글 제목을 한 줄에 하나씩 붙여넣고 **목록 저장**을 누르세요
- Claude가 뜻으로 비교합니다 ("모공 치료" 와 "넓은 모공 시술" 도 같은 주제로 봄)
- 겹치는 글이 있으면 목록과 함께 **겹치지 않는 새 각도**를 제안합니다
  - **겹치지 않게 쓰기**: 제안된 각도(고쳐도 됨)와 이미 쓴 글 목록을 두 AI에게 알려주고, 겹치지 않게 씁니다
  - **그대로 쓰기**: 확인 없이 그냥 씁니다 · **취소**: 요청을 고칩니다 · 목록의 글을 누르면 그 글이 열립니다
- 확인이 필요 없으면 ⚙️ 설정에서 **쓰기 전에 주제 중복 확인**을 끄세요

## 구독 사용량에 대해
- 토론 모드는 글 한 편에 두 AI를 합쳐 **10번 남짓** 부릅니다. 추가 요금은 없지만 구독의 사용량 한도를 씁니다.
- 한도에 닿으면 "구독 사용량 한도에 도달했습니다" 라고 나옵니다. 몇 시간 뒤 한도가 다시 채워지면 이어서 쓰면 됩니다.
- 사용량을 아끼려면 ⚙️ 설정에서 **토론 라운드를 1** 로 줄이거나 **작가·편집자 모드**를 쓰세요.
- 구독 계정은 개인 계정입니다. 이 프로그램은 **본인 PC에서 본인 작업용으로** 쓰세요. 여러 사람이 함께 쓰는 서버에 올리는 용도가 아닙니다.

## `.env` 로 바꿀 수 있는 것 (선택)
`.env.example` 을 복사해 이름을 `.env` 로 바꾸고 고치면 됩니다. 없어도 기본값으로 동작합니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `MODE` | `debate` | `debate`(토론) 또는 `loop`(작가·편집자) |
| `DEBATE_ROUNDS` | `2` | 토론 라운드 (1~4) |
| `CLAUDE_MODEL` / `GPT_MODEL` | (비움) | 비우면 구독 기본 모델. 예: `opus`, `gpt-5.5` |
| `CLINIC_PROFILE` | 선샤인의원 소개 | 글에 들어갈 병원 정보 |
| `TARGET_SCORE` | `8.5` | 목표 점수 |

AI에게 주는 지시문·채점 기준·의료광고 기준은 `duo.py` 위쪽의 한글 문장을 고치면 됩니다.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 설정 옆 점이 빨간색 / "로그인이 필요합니다" | `로그인하기.bat` 실행 → 구독 계정으로 로그인 → 화면 ⚙️ 설정 → **다시 확인** |
| "설치돼 있지 않습니다" | `설치하기.bat` 실행. 설치 직후라면 검은 창을 닫고 `글쓰기.bat` 을 다시 실행 |
| "구독 사용량 한도에 도달했습니다" | 몇 시간 뒤 다시 시도. 급하면 토론 라운드를 줄이기 |
| 점이 노란색 "API 키로 로그인됨" | 구독이 아닌 크레딧이 쓰이는 상태. `로그인하기.bat` 으로 구독 계정 로그인 |
| 예시 글만 짧게 나옴 | 연습 모드가 켜진 것. 로그인 상태를 확인하고 ⚙️ 설정에서 연습 모드 끄기 |
| "프로그램과 연결이 끊겼어요" | 검은 창이 닫힌 것. `글쓰기.bat` 을 다시 실행 |
| 대화 기록을 모두 지우고 싶음 | 프로그램을 끄고 `data` 폴더를 삭제 |

| `web/index.html` | 채팅 화면 |
