# 블로그 글쓰기 기준 (선샤인의원 · 피부과)

## 원고 형식 (`*.md`)
`build` 명령이 이 형식을 워드 파일로 바꾼다. 머리말 값은 워드 마지막 페이지 "SEO 정보" 표로 들어간다.

```markdown
---
title: 검색 결과에 보일 제목 (메인 키워드를 앞쪽에, 25~35자)
keyword: 메인 키워드 1개
sub_keywords: 보조 키워드 2~4개, 쉼표로 구분
meta_description: 검색 결과 요약문 80~120자, 메인 키워드 1회 포함
tags: #태그1 #태그2 ... (5~10개)
---
# 본문 제목 (title 과 같거나 조금 더 구어체)

도입 2~3문장. 독자의 고민/상황으로 시작하고, 이 글에서 얻을 답을 예고.

![alt 텍스트 — 메인 키워드 포함 설명](images/card-01.png "그림 1. 캡션")

## 소제목 (질문형 또는 키워드 포함)
짧은 문단. **핵심 문장 굵게**. 근거가 있는 문장 끝에 [1] 처럼 번호.

- 목록은 3~5개
1. 순서가 있으면 번호 목록

> 한 줄 요약/주의 박스 (글 전체에서 1~2번)

## 마무리 소제목
요약 + 부드러운 행동 유도(상담 권유 수준). 

## 참고 자료
1. 저자. 제목. 저널/기관. 연도. [링크](https://...)
```

지원하는 문법: `#`~`###` 제목, `**굵게**`, `[글자](https://링크)`, `-` 목록, `1.` 번호 목록, `>` 강조 박스, 한 줄짜리 이미지 `![alt](경로 "캡션")`.
표·HTML 은 쓰지 않는다 (필요하면 카드 이미지로).

## 분량
- **본문 공백 포함 2000자 이내** (참고 자료 섹션·이미지 줄·머리말은 제외하고 `count` 가 센다). 목표 1600~1950자.
- 넘치면: 중복 설명 → 일반론 → 부연 예시 순으로 덜어낸다. 원장 고유의 경험·의견은 마지막까지 남긴다.

## SEO (네이버 블로그 · 구글 공통)
- 메인 키워드: 제목 앞쪽, 도입 첫 2문장 안, 소제목 1~2곳, 본문 전체 3~5회 (억지 반복 금지).
- 보조 키워드·연관 표현을 자연스럽게 섞는다 (예: 기미 → 색소, 멜라닌, 레이저토닝).
- 소제목 3~5개, 질문형 소제목 1개 이상 (검색 의도와 일치).
- 이미지 alt 에 키워드 포함, 이미지 1~3장.
- 지역 키워드(잠실·송파)는 마무리에 1회 정도만.

## 가독성
- 한 문장 50자 안팎, 한 문단 2~4문장. 어려운 의학 용어는 처음 나올 때 괄호로 쉽게 풀이.
- 말투: 원본 글의 말투를 따른다. 원본이 불분명하면 친절한 존댓말("~입니다/~예요" 혼용 가능).
- 독자가 3초 훑어봐도 핵심이 보이게: 소제목 + 굵은 문장 + 목록.

## 의학적 정확성
- 근거가 필요한 모든 수치(유병률, 횟수, 기간, 효과)에는 출처 번호를 단다.
- 개인차가 큰 내용은 "개인에 따라 다를 수 있다"는 맥락을 준다.
- 근거를 못 찾은 내용은 쓰지 않거나 `[확인 필요]` 표시 (최종본에서는 사용자에게 보고).

## 의료광고 주의 (의료법 제56조 취지 — 반드시 지킴)
쓰지 않는다:
- 효과 보장·단정: "완치", "100%", "부작용 없음", "재발 없음", "확실한 효과"
- 최상급·비교: "최고", "최초", "유일", "타 병원보다"
- 치료 경험담·후기, 전후 사진(생성 이미지 포함)
- 가격 할인·이벤트로 환자 유인하는 문구
- 검증되지 않은 신의료기술의 효과 주장
대신: "도움이 될 수 있습니다", "개선을 기대할 수 있습니다", "전문의 상담 후 결정" 같은 표현.
부작용·주의사항을 한 줄 이상 포함한다.
