# 베가스 일일 수납 내역 정리

베가스 화면을 직접 조작(컴퓨터 사용: 스크린샷·클릭·스크롤)해서 모든 환자의 '오늘' 수납 팝업을 확인하고 금액을 정리한다.

## 전제 조건
- 베가스가 설치된 **사용자 PC에서** 실행해야 한다 (Claude 데스크톱 앱 / Cowork 의 컴퓨터 사용 기능). 클라우드 컨테이너에서는 베가스 화면에 접근할 수 없다.
- 컴퓨터 사용 도구가 없으면 `anthropic-skills:computer-use` 스킬을 먼저 불러온다. 그래도 화면을 제어할 수 없으면 작업을 멈추고 사용자에게 알린다.
- 베가스는 이미 로그인되어 있어야 한다. 비밀번호를 대신 입력하지 않는다.

## 추출 항목 (팝업 기준)
| 키 | 팝업 표기 |
|---|---|
| `total` | 총진료비 |
| `claim` | 청구액 |
| `copay` | 본인부담금 |
| `nonins_tax` | 비급여(과세) |
| `nonins_notax` | 비급여(비과세) |
| `discount` | 할인 |

금액은 쉼표를 뺀 정수(원)로 기록한다. 빈칸·`-`는 0. 할인이 음수(`-5,000`)로 표시돼도 **양수로** 기록한다(할인 금액 자체).

## 절차

### 1. 화면 파악
1. 베가스 창을 앞으로 가져오고 최대화한다. 스크린샷을 찍는다.
2. 오른쪽 **수납 영역**의 카드리스트를 찾는다. 카드마다 환자 이름(또는 차트번호)과 `오늘` 글씨가 있다.
3. 첫 카드의 `오늘`을 클릭해 팝업 모양을 확인하고, 6개 항목의 위치를 파악한다. 화면 구성이 예상과 다르면 스크린샷을 근거로 사용자에게 확인한다.
4. 팝업 닫는 방법(닫기/확인 버튼, `Esc`)을 확인한다. **저장·수납·취소·삭제·수정 버튼은 절대 누르지 않는다.** 이 작업은 읽기 전용이다.

### 2. 환자별 반복
카드리스트 맨 위부터 순서대로:
1. 카드의 환자 식별 정보(이름, 차트번호, 접수시간 등 보이는 것)를 기록한다.
2. 해당 카드의 `오늘`을 클릭한다.
3. 팝업이 뜨면 스크린샷을 찍고 6개 금액을 읽는다. 숫자가 작거나 흐리면 팝업 영역을 확대(zoom)해서 다시 읽는다.
4. 즉시 검산: `총진료비 ≈ 청구액 + 본인부담금 + 비급여(과세) + 비급여(비과세)` (할인 적용 방식은 병원 설정에 따라 다를 수 있음). 맞지 않으면 한 번 더 확대해서 읽고, 그래도 다르면 `note`에 "검산 불일치"라고 적고 계속 진행한다.
5. 팝업을 닫고, 원래 카드리스트 화면으로 돌아왔는지 스크린샷으로 확인한다.
6. 결과를 `rows.jsonl`에 한 줄씩 바로 추가한다(중간에 끊겨도 이어서 할 수 있도록):
   ```json
   {"no": 1, "patient": "홍길동", "chart_no": "12345", "time": "09:12", "total": 35000, "claim": 24500, "copay": 10500, "nonins_tax": 0, "nonins_notax": 0, "discount": 0, "note": ""}
   ```
7. 화면에 보이는 카드를 다 처리하면 카드리스트를 스크롤한다. 스크롤 후 이미 처리한 카드(이름+차트번호+시간 기준)는 건너뛴다. 스크롤해도 새 카드가 안 나오면 끝.
8. 한 환자가 카드를 여러 장 가지면(재방문 등) 각각 별도 행으로 기록한다.

### 3. 집계
모든 환자를 처리했으면 집계 스크립트를 실행한다:

```bash
python3 .claude/skills/vegas-daily-billing/scripts/summarize.py rows.jsonl --out 수납정리_YYYYMMDD
```

- `수납정리_YYYYMMDD.csv` (엑셀에서 바로 열림, 환자별 행 + 합계 행)
- `openpyxl`이 있으면 `수납정리_YYYYMMDD.xlsx`도 생성
- 터미널에 항목별 합계와 검산 불일치 목록 출력

### 4. 보고
사용자에게 다음을 알려준다:
- 처리한 환자 수, 항목별 합계(총진료비·청구액·본인부담금·비급여(과세)·비급여(비과세)·할인)
- 검산 불일치나 읽기 어려웠던 환자 목록 → 베가스에서 직접 재확인 권장
- 가능하면 베가스 자체 일일 수납 합계 화면과 총액을 대조하라고 안내

## 개인정보 주의
- 환자 이름·차트번호·스크린샷은 **사용자 PC 안에만** 저장한다. 외부 서비스로 전송하거나 git 저장소에 커밋하지 않는다.
- 작업용 스크린샷은 집계가 끝나면 사용자에게 삭제 여부를 묻는다.
